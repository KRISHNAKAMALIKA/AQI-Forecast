Project Name: Air Quality Index (AQI) Forecast
Project Scope: Clean air quality data, analyze pollutant trends across Indian cities, and build ML models (Linear Regression, Random Forest) to predict and forecast AQI.
Dataset
Air Quality Data in India (2015-2020) from Kaggle: city_day.csv
Models and Results
Linear Regression and Random Forest were compared using MAE, RMSE and R2. See results.png and the outputs folder for graphs and the 30-day forecast.
How to run
pip install pandas numpy matplotlib seaborn scikit-learn
Upload city_day.csv and run the notebook, or run: python aqi_forecast.py
